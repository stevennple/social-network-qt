# Social Network QT

This repository contains the source code for a social networking application developed using the Qt framework. The project is primarily written in C++, with additional components in Makefile, C, and QMake.

## Introduction

The Social Network QT project aims to provide a fully-functional social networking application with a user-friendly interface. The application supports various social networking features such as user registration, profile management, posting updates, and more.

## Features

- User Registration and Authentication
- Profile Management
- Posting Updates and Comments
- Friend Requests and Messaging
- Notifications

## Requirements

- Qt 5.15 or later
- C++17 compatible compiler
- Make
